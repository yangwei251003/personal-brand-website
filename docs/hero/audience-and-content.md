# 受众与内容契约

最后更新：2026-08-31

## 受众优先级

1. **自己**：能长期维护、持续替换占位内容，并真实记录成长。
2. **朋友与老师**：快速理解个人方向、阶段成果和成长路径。
3. **招聘者与潜在合作者**：在短时间内验证身份、能力、作品证据与联系方式。

主页同时支持两种阅读速度：前三屏完成 30 秒扫描；后续长页提供 3–5 分钟叙事浏览。

## 一句话任务

让访问者在不依赖任何内页的情况下，回答四个问题：这个人是谁、正在创造什么、如何成长、下一步如何联系。

## 首屏 CTA

- “看精选项目” → `#projects`
- “沿成长轨迹” → `#timeline`
- “与我联系” → `#contact`

三者仅使用本页锚点，不创建 `/projects`、`/about` 或 `/contact`。

## 内容真实性规则

- 个人姓名、学校、职位、项目、奖项、年份、指标、联系方式与外部链接全部使用 `{{TOKEN}}`。
- 页面可以描述槽位职责，不能补写看似合理的假事实。
- 无内容是一种显式状态，不用虚构条目填满版面。
- 图片只提供氛围；所有事实由 HTML 文本和结构化数据表达。
- token 未替换时，按钮使用不可导航状态并说明“待补充”，不生成 `#`、空 URL、`mailto:` 或 `tel:` 坏链接。

## 文案语气

第一人称、直接、克制、具体。强调正在做的事情和可验证证据，不使用“顶尖”“精通”“行业领先”等无法证明的词。
