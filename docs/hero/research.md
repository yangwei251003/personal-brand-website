# Hero 参考研究

研究日期：2026-08-31  
研究范围：个人品牌、作品集、数字简历、长篇单页叙事、紫金至暖橙连续背景。  
方法说明：优先核验个人官网，再以 Awwwards 与 SiteInspire 补充索引。视觉与交互结论是设计推导，不复制任何站点的独特表达。

## 核心结论

本项目采用“70% 内容可信度 + 20% 交互细节 + 10% 标志性氛围”的比例：

- 内容骨架参考 Brittany Chiang、Tania Rascia、Anthony Fu 与 Paco Coursey。
- 微交互节制参考 Rauno Freiberg、Emil Kowalski 与 Josh W. Comeau。
- 氛围强度参考 Dennis Snellenberg、Bruno Simon 与 Lynn Fisher，但不采用滚动劫持、游戏导航或默认声音。

## 案例矩阵

| 案例 | 可迁移模式 | 本项目限制 |
|---|---|---|
| [Brittany Chiang](https://brittanychiang.com/) | 先身份与价值，再经历、项目和写作；明确 skip link | 不照搬深蓝开发者模板，不用标签数量冒充能力 |
| [Dennis Snellenberg](https://dennissnellenberg.com/) | 编辑式大标题、项目图文错位、末段强 CTA | 不采用自定义光标、惯性滚动或内容依赖转场 |
| [Rauno Freiberg](https://rauno.me/) | 节点、档案窗口、状态符号；每区一个值得发现的互动 | 不复制桌面系统；横向画廊和音效不承担导航 |
| [Emil Kowalski](https://emilkowal.ski/) | 克制排版承载少量高质量状态动效 | 不让每张卡都旋转、弹跳或掩盖链接 |
| [Josh W. Comeau](https://www.joshwcomeau.com/) | 主体稳定，彩蛋局部化；适合页尾记忆点 | 不默认播放音效，不让彩蛋抢夺正文 |
| [Paco Coursey](https://paco.me/) | 少量高可信内容；Building、Writing、Now、Connect 紧凑纵向组织 | 极简不能弱化项目证据，联系方式不能藏成小字 |
| [Lee Robinson](https://leerob.com/) | 短身份与长叙事两级信息密度 | 核心身份默认可见，展开控件不是唯一入口 |
| [Adham Dannaway](https://www.adhamdannaway.com/) | 能力分类先于项目细节，适合四类 AI 创作入口 | 移动端改为顺序内容，不依赖 hover 分屏 |
| [Maggie Appleton](https://maggieappleton.com/) | 自有图像语言形成品牌资产，内容按成熟度与主题组织 | 生成图不替代必要文字，不使用无职责通用 AI 图 |
| [Tania Rascia](https://www.taniarascia.com/) | 时间线讲转折、行动与结果 | 首页只保留能说明成长路径的关键节点 |
| [Anthony Fu](https://antfu.me/) | 短句、行内链接和分组承载高密度事实 | 不做工具名堆砌；中文标题不使用夸张字距 |
| [Innei](https://innei.in/) | 主页作为个人内容网络入口，项目、博客和画廊只做摘要 | 当前阶段不创建未授权内页或伪入口 |
| [Lynn Fisher](https://lynnandtonic.com/) | 单一鲜明视觉命题形成版本记忆 | 不把每个区段变成不同组件展览 |
| [Bruno Simon](https://bruno-simon.com/) | 一句话可描述的主视觉概念与完整输入控制 | 不采用 3D 驾驶、强制加载、默认声音或游戏阅读路径 |
| [Robby Leonardi](https://www.awwwards.com/web-design-awards/robby-leonardi) | 成长旅程和里程碑节奏 | 不采用横向滚动、视差劫持或强制游戏化履历 |

## 推荐长页节奏

| 滚动位置 | 内容与色彩职责 |
|---|---|
| 0–18% | 墨黑紫首屏：身份、价值主张、三个本页锚点 CTA |
| 18–35% | 皇家紫身份摘要与精选项目：建立可信度 |
| 35–52% | 紫金 AI 创作入口：四类能力各用一个明确动作词 |
| 52–70% | 香槟金至琥珀：荣誉与成长时间线形成叙事高潮 |
| 70–88% | 暖橙渐退：博客、视频、照片墙降速 |
| 88–100% | 收束为暗色：联系方式、简历占位与记忆点页尾 |

背景由页面根层长渐变和少量区段径向光场连续完成；卡片使用低透明或实体暗色，不为每区单独铺背景。

## 中文排版与信息约束

- 中文正文每行约 24–34 个字符，行高 1.65–1.8。
- 中文展示标题保持接近正常字距；宽追踪只用于英文眉题、编号和元数据。
- 金色只用于编号、状态、细边与短强调；正文保持米白或浅灰。
- 项目卡默认展示标题、职责、状态和结果占位；hover 只增加反馈。
- 先给结论，再给背景；每区标题尽量不超过两行。

## 明确避雷

- 3D、横向滚动、拖拽或游戏操作承担主导航。
- 滚动劫持、强制 loader、默认声音、隐藏系统光标。
- 紫色霓虹、大量玻璃卡片、渐变标题的模板化组合。
- 重要信息只存在于 hover 或 WebGL。
- 用奖项、技能名或工具标签冒充项目成果。
- 生成图包含事实、文字、真实证书、组织徽章或来源不明素材。
