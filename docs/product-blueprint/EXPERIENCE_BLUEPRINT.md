# Experience Blueprint

- Blueprint version：`1.0.0-hero`
- Last updated：2026-08-31
- Status：Approved
- Authority：Hero 页面体验、视觉、响应式、动效与无障碍的唯一权威。

## 体验原则

| 原则 | 可观察行为 | 禁止模式 |
|---|---|---|
| 先读懂，再惊喜 | 首屏文字无需等待图片/JS；每区标题先出现 | loader、逐字解码阻塞理解 |
| 一条连续展览路线 | 背景与轨迹跨区延续，区段由间距而非硬色块分割 | 每区一个独立渐变或组件主题 |
| 成果才升温 | 暖橙只在荣誉、成长结果、联系 CTA 达到峰值 | 全页均匀撒金色与橙色 |
| 空状态也可信 | 占位可见、不可导航、有清楚标签 | 虚构内容、空链接、伪播放按钮 |
| 所有动效可退出 | reduced-motion、Save-Data、触屏和低性能都有静态等价物 | hover-only、滚动劫持、默认声音 |

## 选定视觉方向

DEC-001 冻结为：**A 紫金数字珍藏馆为主，C 暖橙成果区，B 节点轨迹作为向下滚动的连接语言。**

- A 决定首屏材质、暗紫空间、香槟金边线、抽象陈列与整体高级感。
- B 只占约 10%，并只决定 `#ai-creation` 至 `#timeline` 的细线、节点、路径与层次；不引入宇宙 HUD、蓝黑星空、密集粒子或 WebGL。
- C 决定荣誉、成长结果、联系 CTA 的赤陶橙、琥珀、纸纤维与暖金压印感。
- 页尾从暖色重新收束为墨黑紫，完成回环。

## 视觉 tokens

### 色彩

- `ink-950 #09070D`：页面底色。
- `ink-900 #120A18`：实体表面。
- `violet-800 #301347`：深紫过渡。
- `violet-600 #6B2F98`：节点与短强调。
- `champagne-400 #D9B978`：边线、编号、状态。
- `champagne-200 #F0D7A6`：高亮短文本。
- `terracotta-600 #B6482D`：成果区主暖色。
- `amber-500 #DF8C35`：CTA 光场与时间线结果。
- `paper-100 #F3E9DC`：主文字。
- `mist-300 #B8ADB8`：正文次级文字。

正文对比度至少 4.5:1；大字与非文本 UI 至少 3:1。金色不承担长段正文。

### 字体与排版

- 展示标题使用系统中文宋体/衬线回退：`Songti SC`、`STSong`、`SimSun`、serif；正文使用 `Segoe UI Variable Text`、`PingFang SC`、`Microsoft YaHei`、`Noto Sans CJK SC`、sans-serif。最多两套字族，不依赖远程字体。
- 展示标题：`clamp(3rem, 8vw, 8rem)`，中文正常或轻微负字距；不做渐变文字。
- 区段标题：`clamp(2rem, 5vw, 4.5rem)`。
- 正文：16–18px，行高 1.7，中文每行约 24–34 字。
- 英文眉题、编号可使用 0.12–0.22em 宽追踪。

### 布局与材质

- 内容最大宽度 1400px；正文阅读宽度不超过 65ch。
- 桌面 12 列、平板 8 列、移动 4 列；断点 768/1024/1280px。
- 高密区避免三列等宽卡片；优先错位网格、分隔线和留白。
- 玻璃只用于导航与少量悬浮标签；内容卡以实体暗面为主。
- 圆角 18–32px，边线 1px，金属光只出现在局部轮廓。

## 组件契约

- `SmartNav`：skip link、桌面锚点、移动菜单、收缩状态、当前区段提示。
- `HeroStage`：静态海报优先，文字与 CTA 为服务端 HTML。
- `SectionIntro`：英文眉题、中文标题、短说明，统一编号系统。
- `SpotlightSurface`：自研 CSS 静态金属边框；只在 fine pointer hover/focus 显示固定微光。
- `PlaceholderLink`：token 未替换时渲染非链接状态并给出说明。
- `GrowthPath`：CSS/SVG 轨迹，装饰节点 `aria-hidden`，reduced-motion 静态化。
- `MediaPlaceholder`：封面与状态；无真实媒体时不渲染播放控件。
- `ChampagneAction`：仅联系区主 CTA 使用静态金边或用户触发的单次扫光。

React Bits 最终状态：经源码级复核全部退出生产；实现使用等价自研 CSS 组件，仓库不安装 React Bits 或 Motion。

## 交互与动效

| 触发 | 动画/反馈 | 时长/曲线 | 可中断 | 触摸/键盘 | reduced-motion | 低性能降级 |
|---|---|---|---|---|---|---|
| 首次进入 | 标题与 CTA 一次性淡入 | 240–320ms | 是 | 内容默认可读 | 静态或 ≤150ms opacity | 静态首帧 |
| 页面滚动 | 固定外层内的导航内容缩放/变色 | 120–180ms | 是 | 相同状态 | 直接切换 | CSS sticky |
| 区段进入 | 8px 位移 + 透明度，一次性 | 240–320ms | 是 | 相同内容 | 仅 ≤150ms opacity 或静态 | Observer 失效即常显 |
| 成长轨迹 | 静态 SVG 路径，少量节点一次性淡入 | ≤320ms | 是 | 触摸自然滚动 | 完整静态路径 | 无 JS 时静态线 |
| 卡片指针 | fixed central glow on hover/focus | 120–180ms | 是 | 触屏静态；键盘焦点轮廓 | 静态 | 实体卡 |
| CTA | hover/focus 后单次边线扫光 | ≤600ms | 是 | 按压反馈 120–180ms | 静态边线 | 普通按钮 |

不允许持续 RAF、全局 scroll/pointermove、滚动 scrub、滚动劫持、pin、横向接管、自定义光标、默认音频或无限循环。只动画 `transform` 与 `opacity`；同屏运动元素不超过 4 个。

## 无障碍与适配

- `lang="zh-CN"`、单一 H1、区段按 H2 递进；主要 landmarks 完整。
- skip link 为首个可聚焦元素；焦点顺序与 DOM/视觉顺序一致。
- 所有点击目标至少 44×44px；焦点使用 2px 实线 outline。
- 核心信息不依赖颜色、hover、图片或动画。
- 移动菜单使用真实按钮、`aria-expanded`、Esc 关闭与焦点返回。
- 200% 文字缩放不截断；390px 无横向滚动。
- `prefers-reduced-motion`、Save-Data、pointer coarse 和无 JS 均有等价路径。
- 无真实视频时不出现播放按钮；未来视频必须静音、`playsInline`、延迟加载、可暂停、有字幕/文字稿。

## 体验验收

- Given 动画与 JS 均不可用，When 访问 `/`，Then 12 区核心文字、锚点与有效链接仍可理解。
- Given token 未替换，When 聚焦联系方式，Then 不发生导航并读出“待补充”状态。
- Given reduced-motion，When 浏览全页，Then 不出现滚动同步绘制、位移或循环流光。
- Given 390×844，When 打开菜单并使用键盘/触摸，Then 可到达每个本页锚点并关闭菜单。
- Given 无真实视频，When 到达视频区，Then 只显示明确空状态，不出现可操作播放控件。
